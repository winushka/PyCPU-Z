# PyCPU-Z

Аналог CPU-Z на Python с графическим интерфейсом (Tkinter). Показывает
сведения о процессоре, оперативной памяти, системной плате, видеоадаптерах
и операционной системе, а также живую нагрузку ядер и частоту в реальном
времени.

## Возможности

- **Компактное окно** в духе оригинала (540×660, размер фиксирован — как в
  оригинальном CPU-Z), целиком помещается на экране ноутбука. В заголовке ЦП
  и Графики — фирменные значки Intel / AMD / NVIDIA.
- **ЦП** — название, производитель, кодовое имя, семейство/модель/степпинг,
  сокет, набор инструкций, кэш L2/L3, ядра и потоки, частота и множитель.
  Отдельная панель с живой загрузкой каждого ядра.
- **Виртуализация** — честная проверка через CPUID: показывается VT-x/AMD-V,
  отключена ли она в BIOS и не занята ли гипервизором (Hyper-V). Там же SLAT.
- **Память** — объём, занято/свободно, тип (DDR4/DDR5 и т.д.), частота,
  форм-фактор, карточки слотов и индикатор заполнения в реальном времени.
- **SPD** — выбор модуля в списке (как в CPU-Z) и его паспорт: слот, объём,
  тип, частота, производитель, партийный и серийный номера, разрядность шины.
- **Графика** — видеоадаптеры с логотипом вендора, объём видеопамяти (из
  реестра, без обрезки до 4 ГБ), версия и дата драйвера, разрешение и частота
  обновления.
- **ОС** — редакция и сборка Windows, архитектура, дата установки, время
  работы, компьютер и пользователь; плата, чипсет, BIOS, накопители.
- **Тест** — бенчмарк SHA-256 в один поток и во все потоки с оценкой
  масштабирования.
- **Отчёт** — сохранение всех сведений в текстовый файл («Отчёт»).

## Требования

- Windows 10/11
- Python 3.10 или новее
- Сторонние библиотеки **не нужны** — используется только стандартная
  библиотека (Tkinter, ctypes, subprocess и модуль `winreg`).
